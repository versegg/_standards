# Чек-лист соответствия стандарту

Прохождение по этому списку для одного продукта даёт бинарный вердикт: 🟢 на рельсах или нет.

## Структура

- [ ] Есть `README.md` в корне продукта
- [ ] Есть `docs/INDEX.md` (сгенерирован)
- [ ] Есть `marketing/INDEX.md` (сгенерирован, может быть пустой по содержимому)
- [ ] `docs/manual/ru/` существует (если продукт с клиентами)
- [ ] `docs/help/ru/` существует (если есть UI)
- [ ] `docs/tech/` существует, минимум `getting-started.md`
- [ ] `docs/arch/` существует (если серьёзный продукт)
- [ ] `docs/adr/` существует (если >3 разработчиков)
- [ ] `docs/api/` существует (если есть публичный API)
- [ ] `docs/runbook/` существует (если есть прод)
- [ ] `docs/releases/` существует
- [ ] `docs/roadmap/` существует
- [ ] `docs/design/` существует (если есть UI)
- [ ] `marketing/` существует
- [ ] `mockups/` существует (если есть UI)

## Именование

- [ ] Все `.md` файлы в `kebab-case.md`
- [ ] Никаких `01-`, `02-` префиксов
- [ ] Никаких `ru-`, `en-` префиксов (есть подпапки)
- [ ] Нет `docs/old/`, `docs/archive/`, `docs/v1/`
- [ ] Нет `frontend/src/help/`, `frontend/src/docs/`
- [ ] ADR именованы `NNNN-<slug>.md` с ведущими нулями
- [ ] Релизы именованы `YYYY-MM-DD-v<X>.<Y>.<Z>.md`

## Frontmatter

- [ ] Каждый `.md` под `docs/`, `marketing/`, `mockups/` имеет frontmatter
- [ ] У всех manual/help указан `locale`
- [ ] У всех документов указан `owner`
- [ ] У всех документов указан `status`
- [ ] У всех документов указан `last_reviewed` (не старше 6 мес)
- [ ] У всех документов указан `type` из каталога

## Контент

- [ ] В каждом `manual/<locale>/<role>/` есть хотя бы `getting-started.md`
- [ ] В `docs/tech/` есть `getting-started.md` и `architecture-overview.md`
- [ ] В `docs/releases/README.md` есть список релизов с ссылками
- [ ] В `docs/roadmap/` есть `themes.md` и текущий квартал
- [ ] В `marketing/` есть `positioning.md` (если продукт продаётся)
- [ ] В `marketing/showcase/README.md` есть описание, что это
- [ ] Все ADR имеют стандартный Nygard-формат

## Кросс-ссылки

- [ ] `related:` в frontmatter указывает на существующие файлы
- [ ] Ссылки между файлами относительные (не от диска)
- [ ] Никаких ссылок на `deprecated` файлы без пометки
- [ ] Корневой `README.md` ссылается на `docs/INDEX.md` и `marketing/INDEX.md`

## Валидация

- [ ] `tools/validate.ps1 -Product <slug>` завершается без ошибок
- [ ] Warnings из validate — обработаны или задокументированы

## Процесс

- [ ] Команда продукта уведомлена о переходе на стандарт
- [ ] Новые документы пишутся по шаблонам из `_standards/templates/`
- [ ] PR с изменением структуры каталогов проходит ревью с участием тех-лида
