# Как принять оплату, если платёж не прошёл автоматически

## Короткий ответ

1. Откройте **Заказы → заказ**.
2. Нажмите **Подтвердить оплату вручную**.
3. Проверьте, что деньги реально пришли (в личном кабинете провайдера).
4. Подтвердите заказ.

## Когда это нужно

- Клиент говорит «я оплатил», а статус заказа — `pending_payment`.
- Банк-эмитент отклонил платёж, но клиент утверждает обратное.
- Технический сбой провайдера (видно по [статусу провайдера](https://status.yookassa.ru)).
