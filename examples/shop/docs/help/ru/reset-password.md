# Как сбросить пароль

## Короткий ответ

1. На странице входа нажмите **Забыли пароль**.
2. Введите email.
3. Откройте письмо и перейдите по ссылке.
4. Введите новый пароль.

Если письмо не пришло в течение 5 минут — проверьте папку «Спам» или обратитесь в поддержку.
