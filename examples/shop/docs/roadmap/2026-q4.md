# Shop — 2026-Q4

## Контекст

После запуска headless checkout в v1.2.0 — основная ставка квартала на партнёрские интеграции и retention.

## Темы квартала

### Партнёрский API

- **Цель:** 3 партнёра в проде, использующих headless API.
- **Метрика успеха:** ≥5% заказов через партнёров к концу квартала.
- **Ключевые инициативы:**
  - [ ] Партнёрский портал (OAuth flow + dashboard)
  - [ ] Webhook-и с retry + signing
  - [ ] Документация партнёра (генерация из OpenAPI)
- **Связанные эпики:** [../../../tracking/epics/active/partner-api](../../../tracking/epics/active/)

### Retention

- **Цель:** снизить churn на 20%.
- **Метрика:** 30-day retention.
- **Инициативы:**
  - [ ] Программа лояльности (баллы)
  - [ ] Триггерные email-цепочки

### Compliance

- **Цель:** соответствие обновлённым требованиям 152-ФЗ (хранение в РФ).
- **Инициативы:**
  - [ ] Аудит хранилищ
  - [ ] Перенос логов в РФ

## Что НЕ делаем в этом квартале

- Новый конструктор страниц (отложено на 2027-Q1)
- Мобильное приложение (iOS/Android)

## Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| Команда перегружена compliance | средняя | Перераспределить 1 dev из retention |
| Headless API не взлетел | низкая | Fallback — дашборд для партнёров |
