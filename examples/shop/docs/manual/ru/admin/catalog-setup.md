# Настройка каталога товаров

## Шаг 1. Создайте категории

1. **Каталог → Категории**.
2. **Добавить категорию**.
3. Укажите название, slug, родительскую категорию.
4. Сохраните.

![создание категории](screenshots/category-create.png)

## Шаг 2. Настройте атрибуты

Атрибуты — это фильтры на витрине (цвет, размер, материал).

1. **Каталог → Атрибуты**.
2. Создайте атрибут: название, тип (список / число / булево).
3. Укажите, в каких категориях он доступен.

## Шаг 3. Добавьте товары

### Вручную

1. **Каталог → Товары → Добавить**.
2. Заполните название, описание, цену.
3. Загрузите фото.
4. Привяжите к категории.
5. Укажите варианты (если есть).
6. Сохраните.

### Импортом CSV

1. **Каталог → Импорт**.
2. Скачайте шаблон CSV.
3. Заполните по шаблону.
4. Загрузите файл.
5. Проверьте превью.
6. Подтвердите импорт.

Подробности: [../../help/ru/add-product.md](../../help/ru/add-product.md).

## Шаг 4. Настройте SEO

1. В карточке категории — поле **SEO**: title, description, slug.
2. В карточке товара — то же.
