# Начало работы администратора Shop

> Это руководство для администратора магазина: как войти, настроить базовое и подготовить магазин к работе.

## Предусловия

- Аккаунт администратора (создаётся суперадминистратором).
- Доступ к `https://admin.shop.example.com`.

## Шаг 1. Вход

1. Откройте [admin.shop.example.com](https://admin.shop.example.com).
2. Введите email и пароль.
3. Подтвердите 2FA.

## Шаг 2. Настройка магазина

1. Перейдите в **Настройки → Общие**.
2. Укажите название магазина, юридическое лицо, ИНН.
3. Загрузите логотип.
4. Выберите часовой пояс и валюту.

## Шаг 3. Настройка каталога

См. подробное руководство: [catalog-setup.md](./catalog-setup.md).

Кратко:
1. **Каталог → Категории** — создайте дерево категорий.
2. **Каталог → Товары** — добавьте товары (вручную или импортом CSV).
3. **Каталог → Атрибуты** — настройте фильтры (цвет, размер и т.п.).

## Шаг 4. Настройка оплаты

1. **Настройки → Платежи** — подключите провайдера (YooKassa, Tinkoff).
2. Укажите ключи API.
3. Проверьте тестовым платежом.

## Шаг 5. Настройка доставки

1. **Настройки → Доставка** — выберите способы (курьер, самовывоз, почта).
2. Укажите тарифы.

## Если что-то пошло не так

| Симптом | Решение |
|---|---|
| Не приходит email подтверждения | Проверьте SMTP-настройки в **Настройки → Почта** |
| Не проходит тестовый платёж | Проверьте, что используете test-ключи провайдера |
| Не вижу меню «Каталог» | У вас нет прав администратора каталога. Запросите у владельца |
