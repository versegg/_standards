# Начало работы менеджера магазина

> Это руководство для менеджера, который обрабатывает заказы, отвечает клиентам и работает с каталогом.

## Предусловия

- Аккаунт с ролью «Менеджер».

## Шаг 1. Вход

1. Откройте [admin.shop.example.com](https://admin.shop.example.com).
2. Войдите с email и паролем.

## Шаг 2. Обработка заказов

1. **Заказы → Новые** — список заказов, ожидающих подтверждения.
2. Откройте заказ, проверьте состав, адрес, оплату.
3. Нажмите **Подтвердить** или **Отменить** (с указанием причины).

Подробности: [](../../help/ru/order-processing.md)

## Шаг 3. Работа с клиентами

1. **Клиенты** — поиск по email / телефону / имени.
2. Просмотр истории заказов клиента.
3. Обработка возвратов: **Заказы → Возвраты**.
