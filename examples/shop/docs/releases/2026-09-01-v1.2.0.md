# v1.2.0 — 2026-09-01

> Headless checkout и новый платёжный провайдер Tinkoff.

## Highlights

- 🎉 **Headless checkout API**: возможность интегрировать оформление заказа в мобильное приложение или партнёрский storefront. См. [API: POST /api/v1/orders](../api/checkout-create-order.md).
- 🚀 **Платёжный провайдер Tinkoff**: добавлен в дополнение к YooKassa.
- 🐛 **Фискализация**: исправлен баг с двойными чеками при ретраях.

## Breaking changes

⚠️ Параметр `paymentMethod` в `POST /api/v1/orders` теперь ожидает `paymentMethodId` (строка) вместо объекта.

```diff
- "paymentMethod": { "type": "yookassa_card" }
+ "paymentMethodId": "pm_yookassa_card"
```

## New features

- Headless checkout API ([docs](../api/checkout-create-order.md))
- Tinkoff как платёжный провайдер
- Webhook-и для `order.paid`, `order.cancelled`

## Improvements

- p95 latency каталога снижен с 180ms до 95ms
- Размер Docker-образа API: 820 MB → 540 MB

## Bug fixes

- Двойные фискальные чеки при ретрае оплаты
- Падение админки при импорте >10k товаров

## Infrastructure

- Redis 7.2 (был 7.0)
- Postgres 16.3 (был 16.1)

## Upgrade

```bash
helm upgrade shop deploy/charts/shop --version 1.2.0
dotnet ef database update --project src/Shop.Persistence
```
