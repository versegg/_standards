# Shop — компоненты

Каталог UI-компонентов. Источник истины — Figma (`https://figma.com/shop-design-system`). Эта страница — текстовая карта.

## Базовые

- **Button** — primary, secondary, ghost; размеры sm/md/lg.
- **Input** — text, number, password, search; состояния default/focus/error/disabled.
- **Select** — single, multi.
- **Checkbox**, **Radio**.
- **Switch**.

## Layout

- **Container** — max-width, padding.
- **Grid** — 12-column.
- **Stack** — vertical spacing.
- **Card**.

## Feedback

- **Alert** — info, success, warning, error.
- **Toast** — top-right, auto-dismiss.
- **Modal** — focus-trap, ESC to close.
- **Skeleton** — loading states.

## Сложные

- **ProductCard** — карточка товара в каталоге.
- **CartItem** — позиция в корзине.
- **OrderSummary** — сводка заказа.
- **CheckoutSteps** — шаги оформления.
