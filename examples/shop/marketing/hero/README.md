# Shop — hero media

Актуальное hero-медиа для лендинга.

## Текущий актуальный

- `final/hero-loop.mp4` — зацикленное видео (8 сек), для главной лендинга.
- `final/hero-still.jpg` — статичная версия для случаев без видео (превью в соцсетях, email).

## Структура

| Папка | Что внутри |
|---|---|
| `final/` | Одобренные и опубликованные варианты |
| `prompts/` | Промпты для генерации (Midjourney, Sora, Runway) |
| `rejected/` | Отклонённые варианты с пометкой почему |

## Когда обновлять

- Раз в 6 месяцев (плановый рефреш).
- При запуске новой ключевой фичи.
- При ребрендинге.
