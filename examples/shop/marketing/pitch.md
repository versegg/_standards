# Питч Shop

## Elevator (30 секунд)

> Мы — Shop, e-commerce платформа для российского бизнеса. Headless API, compliance из коробки, запуск за 2 недели. В отличие от Shopify, мы храним данные в РФ и фискализируем по ФЗ-54.

## Extended (3 минуты)

### Проблема

Российский e-commerce растёт, но западные платформы не решают регуляторику, а самопис — дорого.

### Решение

Headless API + встроенный 152-ФЗ + ФЗ-54 + multi-tenant.

### Почему сейчас

- 152-ФЗ ужесточается, штрафы растут.
- Бизнес хочет быстро выходить в новые каналы (мобайл, партнёры).
- Shopify не работает на РФ-рынке — освободившаяся ниша.

### Почему мы

Команда: 5 человек с опытом в e-commerce и compliance (ex-Yandex, ex-Ozon).

### Метрики (по состоянию на 2026-09-01)

- 12 клиентов в проде
- 47 млн ₽/мес GMV через платформу
- 110% рост MoM (средний за последние 6 мес)

## Demo script

1. Открыть [https://demo.shop.example.com](https://demo.shop.example.com).
2. Показать каталог (admin) → публичную витрину.
3. Пройти оформление заказа с фискализацией.
4. Показать webhook, который получил партнёр.
5. Показать дашборд с метриками GMV.

## FAQ по возражениям

### «Чем вы отличаетесь от Shopify?»

→ Shopify не решает 152-ФЗ и не имеет русской фискализации. Подробно — в [конкурентном анализе](./competitive.md).

### «Почему не 1С-Битрикс?»

→ Битрикс — это коробка с UI, headless API ограничен. Для мобильного приложения или партнёрской витрины — не подходит.

### «Это безопасно?»

→ Да, данные хранятся в РФ (Yandex Cloud), аудит Роскомнадзора пройден, ISO 27001 в процессе.
