# Позиционирование Shop

## Одной строкой

> Для **среднего и крупного e-commerce бизнеса в РФ** мы — **headless платформа с встроенным compliance**, которая **позволяет запускать магазин за 2 недели и не думать про 152-ФЗ**, в отличие от **западных SaaS, которые не решают российские регуляторные требования**.

## Проблема клиента

Российский e-commerce растёт на 25% год-к-году. Бизнесы хотят быстро запускать новые каналы продаж (мобильное приложение, партнёрские витрины), но:

- западные SaaS (Shopify, BigCommerce) **не соответствуют 152-ФЗ** — данные хранятся за рубежом, нет фискализации под ФЗ-54;
- самописные решения **дорого поддерживать** — 3 разработчика на старте, 12 — через год;
- on-premise коробки **не дают headless** — привязка к UI, нет API для партнёров.

## Наше решение

Shop — e-commerce платформа с:

- **Headless API** для любых витрин (веб, мобильное, партнёрское).
- **Встроенным compliance** (152-ФЗ, ФЗ-54, GDPR).
- **Multi-tenant** — несколько storefront на одной установке.

## Ключевые преимущества

1. **Запуск за 2 недели** — измеримо: median time-to-launch = 14 дней.
2. **Compliance из коробки** — ФЗ-54 фискализация, хранение в РФ, DSAR.
3. **Headless API** — любой фронт, любой партнёр.
4. **Predictable cost** — фиксированная цена за tenant, без % с оборота.

## Чем отличаемся от конкурентов

| | Shop | Shopify | 1С-Битрикс | Самопис |
|---|---|---|---|---|
| Headless API | ✅ | ⚠️ (только Storefront API) | ⚠️ (ограниченный) | ✅ |
| 152-ФЗ из коробки | ✅ | ❌ | ⚠️ (частично) | ⚠️ (если делать) |
| ФЗ-54 фискализация | ✅ | ❌ | ⚠️ (через модули) | ⚠️ (если делать) |
| Multi-tenant | ✅ | ❌ | ❌ | ❌ |
| Time-to-launch | 2 нед | 1 нед | 4–8 нед | 3–6 мес |
